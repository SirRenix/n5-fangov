      n5-fangov  beta
      
    
      A fan governor for small servers whose EC or Super-I/O exports its fan outputs through a kernel hwmon driver. The daemon takes over the pwm channels the driver exposes, drives each from its own curve with a selectable temperature source (CPU package, NVMe max, drive max, EC and other hwmon sensors), slews between steps and stands guard: a critical temperature forces full duty, a stall (fan reports 0 rpm) kicks the channel up, a systemd watchdog restarts a hung daemon and the failsafe leaves the channels at a safe duty when it stops. This dashboard and the n5-fangov CLI share one API.

        PEM certificate (chain allowed) and its private key. The pair is validated (key type usable by this server, a test handshake, not expired), stored under /etc/n5-fangov/tls/ and served immediately; [web].tls becomes file. Encrypted keys are refused — decrypt with openssl first.
        
      
      
      
      
      
      
        
    
        
    
        
      How to trust this certificate
      
          
        
        1. Windows: download .cer → double-click → Install Certificate → Local Machine → Place all certificates in the following store → Trusted Root Certification Authorities. Chrome and Edge pick it up after a restart.
          2. 
        
        2. macOS: download .crt → open it in Keychain Access → keychain System → double-click the entry → Trust → Always Trust. Safari and Chrome use it at once.
          3. 
        
        3. Firefox: Settings → Privacy & Security → Certificates → View Certificates → Authorities → Import the .crt → tick Trust this CA to identify websites.
          4. 
        
        4. Android: download .cer → Settings → Security → Encryption & credentials → Install a certificate → CA certificate → pick the file.
          5. 
      
        
      
        The certificate is self-signed with name constraints for exactly its own names: trusting it cannot vouch for any other host. Linux CLI: copy the .crt to /usr/local/share/ca-certificates/ and run update-ca-certificates.
